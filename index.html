Panduan Penggunaan Dashboard
5 langkah untuk mulai tracking affiliate lo
1
Apa yang dibutuhkan
Dashboard ini menggabungkan dua sumber data: Meta Ads CSV (data spend & klik iklan) dan Shopee Affiliate CSV (data komisi). Di versi Barry, hasil analisa bisa disimpan ke server dan dibuka lagi lewat menu History.
2
Samakan range tanggal
Pastikan range tanggal Meta CSV dan Shopee CSV sama persis. Kalau Meta hanya 1 hari tapi Shopee 7 hari, ROAS yang muncul akan menyesatkan — dashboard akan otomatis kasih peringatan kuning.
Contoh yang benar: Meta export 24–30 Mar · Shopee export 24–30 Mar
Contoh yang salah: Meta export 30 Mar · Shopee export 24–30 Mar
3
Format file
Kedua file harus dalam format .CSV. Jangan ubah nama kolom atau format isi file — dashboard membaca nama kolom secara langsung dari header CSV.
1
Buka Meta Ads Manager
Pergi ke Ads Manager → Campaigns. Pastikan lo berada di level Campaign, bukan Ad Sets atau Ads.
2
Set kolom yang dibutuhkan
Klik Columns → Customize Columns, tambahkan:

Amount spent · Link clicks atau Unique link clicks · Landing page views · Impressions · CPC (link) · CPM · CTR (link)
3
Set breakdown dan export
Klik Breakdown → By Time → Day supaya data per hari muncul. Pilih range tanggal yang diinginkan, lalu klik Export → Export Table Data (CSV).
Penting: Tanpa breakdown by Day, semua data akan jadi satu baris dan chart harian tidak bisa ditampilkan.
1
Buka panel Shopee Affiliate
Login ke affiliate.shopee.co.id → pilih menu Komisi atau Commission Report.
2
Set filter tanggal
Set range tanggal yang sama dengan Meta CSV. Shopee menggunakan Waktu Pemesanan (tanggal order) sebagai basis filter.
3
Export CSV
Klik tombol Export atau Unduh. File yang didownload langsung bisa diupload ke dashboard tanpa modifikasi apapun.
Catatan: Order dengan status Dibatalkan otomatis dikeluarkan. Order Tertunda tetap dihitung karena cancel rate hanya sekitar 1–2%.

Soal perbedaan angka komisi: Wajar kalau total komisi di sini lebih rendah dari angka di dashboard Shopee. CSV pakai Komisi Bersih (sudah diverifikasi), dashboard Shopee pakai Komisi Kotor (belum final). Selisihnya mengecil kalau export dilakukan beberapa hari setelah periode berakhir.
1
Filter Sumber Trafik
Dashboard memisahkan trafik ke 4 grup: Social Media (Facebook/Instagram), Shopee Video, Shopee Live, dan Organik. Klik grup atau platform individual untuk lihat performa masing-masing channel secara terpisah.
Use case: Lo lagi live Shopee sambil jalan iklan Meta — filter ke "Social Media" buat lihat ROAS iklan aja, atau ke "Shopee Live" buat lihat komisi organik dari live.
2
Warna ROAS sebagai sinyal cepat
Hijau ≥ 1.5x kandidat scale bertahap kalau tidak ditopang 1–2 komisi jumbo
Amber 1–1.49x HOLD, jangan scale selama belum kuat
Merah < 1x Rugi; kalau spend ≥ Rp60rb, KILL
3
LP Rate di tab Campaigns
Landing Page Rate = % orang yang klik iklan Meta dan benar-benar sampai ke halaman Shopee. Di bawah 20% (merah) berarti ada price mismatch.
Target LP Rate: Hijau ≥ 40% · Amber 20–40% · Merah < 20%
4
Zero Komisi rate
Persentase order item yang masuk tapi menghasilkan Rp 0 komisi. Idealnya di bawah 30%.
1
Kenapa tag penting
Tanpa tag, dashboard tidak bisa tahu komisi mana yang berasal dari campaign Meta mana. Tab Atribusi akan kosong dan ROAS per-campaign tidak bisa dihitung.
2
Cara set tag di Shopee
Saat generate link affiliate di panel Shopee, isi kolom Tag_link1 dengan nama campaign Meta lo. Gunakan format yang mudah diidentifikasi:

Campaign Meta: cetak barcode 1 → Tag: cetak-barcode-1
Aturan matching: Dashboard mencocokkan tag ke campaign secara fuzzy — kalau tag mengandung sebagian nama campaign atau sebaliknya, akan otomatis ter-match.
3
Satu link per campaign
Untuk tracking yang akurat: satu campaign Meta = satu link Shopee dengan tag unik. Jangan pakai link yang sama untuk dua campaign berbeda.
